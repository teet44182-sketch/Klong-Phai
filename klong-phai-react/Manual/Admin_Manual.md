# คู่มือการดูแลระบบเว็บไซต์ Klongpai
**สำหรับเจ้าหน้าที่ดูแลระบบ (Administrator)**

---

## 1. การเข้าสู่ระบบผู้ดูแลระบบ (Admin Access)
1. เข้าสู่ระบบผ่าน Gmail: `klongpaitravel@gmail.com` 
2. ดำเนินการเข้าสู่ระบบด้วยบัญชี **Google OAuth 2.0**
3. **เงื่อนไขสิทธิ์ในการเข้าถึง (Admin Authentication):**
   - ระบบจะอนุญาตให้เข้าสู่หน้าแผงควบคุมระบบ (Admin Dashboard) เฉพาะบัญชี **Gmail ที่ได้รับสิทธิ์เฉพาะ** ตามที่ระบุไว้ในระบบเท่านั้น
4. หากเข้าสู่ระบบด้วย Gmail ที่ได้รับสิทธิ์ เมนู **"เพิ่มสถานที่ (Add Place)"**  และ **"ยอดเข้าชม (Analytics)"** จะปรากฏขึ้นโดยอัตโนมัติ

---

## 2. การจัดการข้อมูลสถานที่ท่องเที่ยว (Places Management)
เจ้าหน้าที่ Admin มีสิทธิ์จัดการข้อมูลสถานที่ทั้งหมดในระบบ:
- **เพิ่มสถานที่ใหม่ (Create):** กรอกชื่อสถานที่ คำอธิบาย พิกัด ละติจูด/ลองจิจูด รูปภาพ หมวดหมู่ เวลาทำการ และเบอร์ติดต่อ
- **แก้ไขสถานที่ (Edit):** ปรับปรุงข้อมูล รูปภาพ หรือรายละเอียดของสถานที่ที่มีอยู่
- **ลบสถานที่ (Delete):** ลบสถานที่ที่ไม่เปิดให้บริการ หรือลบข้อมูลที่ไม่ใช้งานแล้ว

---

## 3. การจัดการโปรโมชันและข่าวประชาสัมพันธ์ (Promotions Management)
- **เพิ่มโปรโมชัน (Create Promotion):** เพิ่มแบนเนอร์ข่าวสาร สิทธิพิเศษ หรือกิจกรรมท่องเที่ยวประจำเทศกาล
- **แก้ไข/ลบโปรโมชัน:** อัปเดตสถานะการใช้งาน หรือลบโปรโมชันที่หมดอายุแล้ว

---

## 4. การดูรายงานสถิติ (Analytics & Daily Views)
ระบบมีแดชบอร์ดสรุปผลการเข้าชมเพื่อช่วยในการวางแผนยุทธศาสตร์การท่องเที่ยว:
- **Analytics (`analytics` collection):** สถิติจำนวนผู้ใช้งาน สถิติการใช้งานฟีเจอร์จัดทริป
- **Daily Views (`dailyViews` collection):** รายงานยอดผู้เข้าชมเว็บไซต์แบบรายวัน เพื่อดูแนวโน้มความสนใจของนักท่องเที่ยว

---

## 5. การจัดการรีวิว (Reviews Moderation)
Admin สามารถตรวจสอบและจัดการรีวิวที่ไม่เหมาะสม:
- ตรวจสอบรีวิวทั้งหมดในระบบ
- ทำการลบรีวิวที่มีข้อความไม่สุภาพ สแปม หรือขัดต่อศีลธรรมอันดี

---

## 6. ข้อควรระวังและแนวปฏิบัติที่ดี (Best Practices)
1. **การรักษาความปลอดภัยของบัญชี:** ห้ามแชร์บัญชี Gmail ที่มีสิทธิ์ Admin ให้บุคคลภายนอก และต้องรักษารหัสผ่านของบัญชีให้ปลอดภัย
2. **การเพิ่ม/เปลี่ยน Gmail Admin:** หากมีการเปลี่ยนตัวเจ้าหน้าที่ดูแลระบบ ให้ประสานงานฝ่าย IT เพื่อแก้ไขรายชื่อ Gmail ที่อนุญาตในระบบ
3. **การตรวจสอบพิกัด Maps:** ตรวจสอบพิกัด Latitude และ Longitude ให้ถูกต้องก่อนบันทึกสถานที่ทุกครั้ง
